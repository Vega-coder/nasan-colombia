# NASAN Colombia · Herramientas, Insumos y Maquinaria

E-commerce y catálogo oficial de equipamiento para laboratorios y talleres de reparación móvil para **NASAN Colombia By: Jordan Duran** (@nasancolombia) — *Herramientas, Insumos y Baterías*.

Stack: **React 19 + Vite + Tailwind CSS 3 + React Router 7 + Vitest**, desplegable en **Vercel**.

1. **NA - CLN**: Máquina de prensado profesional 110V / 220V bi-voltaje ($1.700.000).
2. **NA - SP23 ULTRA**: Plancha térmica giratoria 360° para pantallas LCD, OLED planas y curvas ($480.000).

## Funcionalidades

- **Home Oficial**: Hero interactivo con rotación 3D de maquinaria, slogan oficial "HERRAMIENTAS · INSUMOS · BATERÍAS", ticker animado, pilares de producto, categorías destacadas y banners editoriales.
- **Catálogo Técnico**: Filtrado por categorías (Maquinaria, Herramientas, Insumos, Baterías, Novedades, Ofertas), búsqueda en vivo, filtros por precio y líneas de aplicación.
- **Detalle de Producto**: Galería interactiva con zoom, selector de fotos y miniaturas de ángulos, badges técnicos oficiales (ej. 110V/220V, Laminación 3D Soft), especificaciones y botón directo a WhatsApp.
- **Carrito y Checkout**: Panel lateral rápido, validación de datos para Colombia y enlace de confirmación directo con resumen para WhatsApp.
- **Panel de Administración**: `/admin` con estadísticas de ventas, inventario y gestión de pedidos.
